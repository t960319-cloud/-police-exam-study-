# 交接包功能合併

日期：2026-11-12（Asia/Taipei）。以 GitHub `fc0e955` 為基礎，依使用者授權選擇性合併交接包的三項功能；未整包覆蓋，也未發布環境或部署網站。

## 合併內容

- 弱點複習：首頁主題依答錯率、複習到期、最近練習及法條掌握度排序並顯示原因；每日選題使用同一份排序，排除教材及個人待核題目。
- 法規時效：開啟解析後並列考試當年答案與現行作答對照；待核、未生效及分階段施行分別提示。選擇及申論待核項目可集中搜尋、開啟。
- 手機篩選：年度、科目、錯題／待複習／收藏優先顯示，其他條件收進進階篩選；收合仍保留條件摘要。原卷資訊可展開查閱。
- 加入 `pnpm test:priorities`、CI 排序測試及新功能的瀏覽器回歸。

交接包以較早來源為基礎，沒有包含目前犯罪偵查六年份題庫與若干後續修正，因此未採用其移除這些成果的差異。

- 保留 910 道選擇、66 道申論及全部原題、官方答案、特殊給分、更正與紀錄鍵。
- 保留犯罪偵查原卷入口、指紋附圖、答案對照及「考點說明・本站整理」標示。
- 原有學習同步、帳號隔離、衝突及版本還原、指定驗收紀錄排除保護、頂層登入跳轉均未修改。
- 資料庫 schema、既有遷移、環境專用設定、預覽及 connector-preview、依賴鎖定檔均未修改。
- 保留 Ubuntu 24.04 與 runner Chrome 的 CI 設定，只增加排序測試。
- 法規補核文件及查核結論維持目前版本；沒有把交接包來源環境的歷史連線結果當作此環境的新查證結果。
