# 警察四等特考複習站

繁體中文、手機優先的個人警察特考工作台，使用 Vinext、React 與 Cloudflare D1。

## 內容
- 40 道主題選擇題、160 項選項解析；32 張法條與程序卡；12 道申論與參考架構。
- 題目搜尋及科目、主題、難度、掌握狀態、內容查證篩選。
- 作答、錯題、收藏、法條熟悉度、申論五段草稿、每日安排、專注紀錄。
- 依臺灣日期安排平日60分鐘、週末120分鐘；支援列印、純文字複製、JSON備份合併與自建題目。

## 內容維護
`lib/study-data.ts` 保存主題、選擇題、法條原文、原文連結、核對日期與待查證事項。原題整理與主題改編分別標示。行政規則未取得完整最新版者，必須保留版本疑點；法條原文與整理摘要不可混稱。初次內容整理日：2026-11-09；後續逐項核對見題目版本註記及查證紀錄。

單一窗口114年版細部時限、解送注意事項原件、失蹤完整最新版、追緝SOP、越區通報最新版及拒測抽血相關函釋，保留人工查證項目。本站不自動更新法律，不提供AI閱卷分數。

## 保存
`db/schema.ts` 的 `study_records` 以站內穩定使用者ID與紀錄鍵複合索引保存。`app/api/records/route.ts` 每次操作驗證登入身分並限定使用者範圍；正式環境拒絕匿名請求。開發環境僅使用獨立的 local-preview 身分。localStorage提供本機快取與待同步佇列，按紀錄時間合併，網路恢復後重試。

原始碼與部署設定由Sites維護。D1結構變更使用Drizzle遷移；不得於請求處理時建表或更改已套用遷移。

## 驗證
- `node node_modules/typescript/bin/tsc --noEmit`
- 使用Sites提供的build-site.mjs建置。
- 已核對題數、唯一答案、160項解析、法條引用、四科與九主題覆蓋、申論配分。
- 已用瀏覽器測試搜尋、篩選、作答、錯題與收藏、重新整理後保存、法條遮罩、熟悉度及申論草稿；以390px框架視窗測試手機操作及無水平溢出。
- 本機資料庫與正式資料庫分離；不將測試學習紀錄作為使用者初始進度。

## 進度保存與同步回歸檢查

- `pnpm lint`：React Hooks、相依項目與型別規則。
- `pnpm exec tsc --noEmit`：TypeScript 型別檢查。
- `pnpm test:sync`：20 項同步回歸測試，涵蓋離線重載、同步中的編輯、跨分頁、伺服器版本衝突、儲存失敗、損壞快取及備份合併；使用記憶體儲存與模擬請求，不寫入正式資料庫。
- `pnpm build`：完整應用程式建置。

本機快取、待同步佇列及版本依伺服器確認的帳號分區；未登入紀錄與舊版未綁定資料不會自動上傳。每次寫入由伺服器核對帳號與讀取時的版本，其他裝置已有修改就回報衝突，保留兩份內容供選擇，不以裝置時間直接覆蓋。匯入備份保留原始時間戳並驗證帳號沒有在讀檔途中變更。瀏覽器儲存失敗會顯示警示。

功能回歸應另在本機 D1 驗證：作答、收藏、錯因筆記、法條熟悉度、申論各段與自評，重新整理後仍存在；切換申論年度後草稿不混用題號；暫停 API 連線後編輯及重載，恢復連線可清空待同步佇列，並由全新瀏覽器讀回。測試後清除測試紀錄。

## 帳號、衝突與版本還原

設定與備份內可確認目前帳號、處理多裝置衝突、選擇紀錄並還原版本。帳號切換會重新建立頁面狀態，避免保留前一個帳號的題目視窗、草稿或計時器狀態。舊版未綁定資料只提供匯出，確認屬於自己後才手動匯入。

資料庫新增 `study_record_versions`，每筆紀錄保留最近20個雲端舊版本；此裝置另保留最多20個修改版本。還原會建立新的條件式寫入，仍受多裝置衝突保護。部署時必須先由既有發布流程套用新增的 `drizzle/0002_typical_mongu.sql` 遷移；本次開發僅套用本機資料庫，沒有操作正式資料或發布。

`pnpm test:browser` 自行建立臨時 D1、套用遷移並啟動專用開發伺服器，測試保存、離線重載、備份、兩裝置衝突與還原、不同帳號的紀錄及歷史隔離、原子版本比對、手機版，以及正式模式的匿名存取拒絕。正式模式檢查需先執行 `pnpm build`。測試完成會刪除專用資料庫；失敗時保留 `.sites-runtime/browser-check-*/server.log`，不使用日常開發或正式 D1。

瀏覽器依賴獨立安裝，不變更應用程式鎖定檔：

```sh
npm install --prefix /tmp/police-study-browser --cache /tmp/police-study-npm --no-package-lock --no-audit --no-fund playwright@1.65.0
node /tmp/police-study-browser/node_modules/playwright/cli.js install chromium
STUDY_BROWSER_MODULE=/tmp/police-study-browser/node_modules/playwright/index.mjs pnpm test:browser
```

已有 Chromium 時可設定 `STUDY_CHROMIUM_PATH`。GitHub Actions 的 `quality.yml` 執行 lint、型別、同步測試、題庫驗證、建置及瀏覽器流程，只讀取儲存庫，不部署或推送程式碼。
