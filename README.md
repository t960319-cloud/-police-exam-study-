# 警察四等特考複習站

繁體中文、手機優先的個人警察特考工作台，使用 Vinext、React 與 Cloudflare D1。

## 內容
- 共 910 道選擇題、66 道申論、32 張法條與程序卡，分為 5 個科目分類及 22 個主題。
- 包含 40 道主題選擇、12 道主題申論，以及 30 份110～115年歷屆卷的870道選擇、54道申論；歷屆範圍為內軌警察勤務、內軌情境實務、內軌犯罪偵查及內外軌警察法規。
- 題目搜尋及科目、主題、難度、掌握狀態、內容查證篩選。
- 作答、錯題、收藏、法條熟悉度、申論五段草稿、每日安排、專注紀錄。
- 依臺灣日期安排平日60分鐘、週末120分鐘；支援列印、純文字複製、JSON備份合併與自建題目。

## 內容維護
`lib/study-data.ts` 保存主題、選擇題、法條原文、原文連結、核對日期與待查證事項。原題整理與主題改編分別標示。行政規則未取得完整最新版者，必須保留版本疑點；法條原文與整理摘要不可混稱。初次內容整理日：2026-11-09；後續逐項核對見題目版本註記及查證紀錄。

單一窗口114年版細部時限、解送注意事項原件、失蹤完整最新版、追緝SOP、越區通報最新版及拒測抽血相關函釋，保留查證項目。法規經查核後由網站版本發布，不保證即時更新或全站均已核完；本站不提供AI閱卷分數。

## 保存
`db/schema.ts` 的 `study_records` 以站內穩定使用者ID與紀錄鍵複合索引保存。`app/api/records/route.ts` 每次操作驗證登入身分並限定使用者範圍；正式環境拒絕匿名請求。開發環境僅使用獨立的 local-preview 身分。localStorage提供依帳號分區的本機快取與待同步佇列，寫入時以伺服器版本比對保護多裝置修改；網路恢復後重試，衝突時保留兩份供選擇。

原始碼與部署設定由Sites維護。D1結構變更使用Drizzle遷移；不得於請求處理時建表或更改已套用遷移。

## 驗證
- `node node_modules/typescript/bin/tsc --noEmit`
- 使用Sites提供的build-site.mjs建置。
- 既有題庫驗證涵蓋題數、選項解析、官方答案更正、特殊給分、法條引用及申論配分；現行法規完整性仍依各題查證標記判讀。
- 已用瀏覽器測試搜尋、篩選、作答、錯題與收藏、重新整理後保存、法條遮罩、熟悉度及申論草稿；以390px框架視窗測試手機操作及無水平溢出。
- 本機資料庫與正式資料庫分離；不將測試學習紀錄作為使用者初始進度。

## 進度保存與同步回歸檢查

- `pnpm lint`：React Hooks、相依項目與型別規則。
- `pnpm exec tsc --noEmit`：TypeScript 型別檢查。
- `pnpm test:sync`：20 項同步回歸測試，涵蓋離線重載、同步中的編輯、跨分頁、伺服器版本衝突、儲存失敗、損壞快取及備份合併；使用記憶體儲存與模擬請求，不寫入正式資料庫。
- `pnpm test:priorities`：6 項個人化排序測試，涵蓋弱點、練習間隔、法條掌握度、到期優先與待核題排除；不修改學習紀錄。
- `pnpm build`：完整應用程式建置。

本機快取、待同步佇列及版本依伺服器確認的帳號分區；未登入紀錄與舊版未綁定資料不會自動上傳。每次寫入由伺服器核對帳號與讀取時的版本，其他裝置已有修改就回報衝突，保留兩份內容供選擇，不以裝置時間直接覆蓋。匯入備份保留原始時間戳並驗證帳號沒有在讀檔途中變更。瀏覽器儲存失敗會顯示警示。

功能回歸應另在本機 D1 驗證：作答、收藏、錯因筆記、法條熟悉度、申論各段與自評，重新整理後仍存在；切換申論年度後草稿不混用題號；暫停 API 連線後編輯及重載，恢復連線可清空待同步佇列，並由全新瀏覽器讀回。測試後清除測試紀錄。

## 帳號、衝突與版本還原

設定與備份內可確認目前帳號、處理多裝置衝突、選擇紀錄並還原版本。帳號切換會重新建立頁面狀態，避免保留前一個帳號的題目視窗、草稿或計時器狀態。舊版未綁定資料只提供匯出，確認屬於自己後才手動匯入。

資料庫新增 `study_record_versions`，每筆紀錄保留最近20個雲端舊版本；此裝置另保留最多20個修改版本。還原會建立新的條件式寫入，仍受多裝置衝突保護。部署時由 Sites 發布流程先套用新增的 `drizzle/0002_typical_mongu.sql` 遷移；2026-11-12 已完成新版正式發布，真實登入與正式 API 的後續驗收狀態見[正式版本對齊紀錄](docs/release-alignment-2026-11-12.md)。

`pnpm test:browser` 自行建立臨時 D1、套用遷移並啟動專用開發伺服器，測試保存、離線重載、備份、兩裝置衝突與還原、不同帳號的紀錄及歷史隔離、原子版本比對、手機版，以及正式模式的匿名存取拒絕。正式模式檢查需先執行 `pnpm build`。測試完成會刪除專用資料庫；失敗時保留 `.sites-runtime/browser-check-*/server.log`，不使用日常開發或正式 D1。

瀏覽器依賴獨立安裝，不變更應用程式鎖定檔：

```sh
npm install --prefix /tmp/police-study-browser --cache /tmp/police-study-npm --no-package-lock --no-audit --no-fund playwright@1.65.0
node /tmp/police-study-browser/node_modules/playwright/cli.js install chromium
STUDY_BROWSER_MODULE=/tmp/police-study-browser/node_modules/playwright/index.mjs pnpm test:browser
```

已有 Chromium 時可設定 `STUDY_CHROMIUM_PATH`。GitHub Actions 的 `quality.yml` 固定使用 Ubuntu 24.04，透過 `playwright-core` 和 runner 預裝的 Google Chrome 執行瀏覽器測試，避免額外下載瀏覽器與安裝作業系統套件；找不到 Chrome 時會明確失敗。流程執行 lint、型別、同步測試、題庫驗證、建置及瀏覽器檢查，只讀取儲存庫，不部署或推送程式碼。

本次法規補核另補入採樣許可及法院救濟，並更正《解送人犯辦法》110.12.13廢止的狀態；相關舊條文只作歷史資料。法規補核範圍、尚缺原件與剩餘連線限制見 [法規待查證清單](docs/legal-verification.md)。未取得官方依據的內容仍保留待查證標示。

## 犯罪偵查歷屆原卷
110～115年內軌四等《犯罪偵查概要》6份、300題已收錄，行政及交通警察共用卷僅保存一份。保留原始題文、初始答案、官方最終清冊、5項更正及每題考點說明。外軌四等行政警察未設此科，《犯罪學概要》不混入。

本次匯入以官方答案對照與本站考點說明呈現；相關現行行政規則未完整覆核者標示需要查證。110年第1題指紋附圖由官方PDF第1頁連結查看。原卷PDF及答案連結指向考選部，站內另存題文文字檔；未將文字檔標為含圖完整PDF。

驗證：`node scripts/check-investigation-papers.mjs` 檢查300題及1200個選項的原文對照、初始與最終答案、給分方式、唯一ID、年度與科目標籤。

## 個人化複習與法規版本

首頁從所有主題依答錯率、到期複習、距離最近練習的天數及法條掌握度選出優先 8 個，並列出推薦原因。作答紀錄不足時，會安排尚未練習的主題；已掌握題目降低歷史錯題的排序影響。每日練習沿用這份排序，先選到期或待複習的題目，排除內容待核與個人標記需要查證的題目，最多 8 題。排序只讀取既有進度，不建立新的紀錄格式。

歷屆題目確認答案或直接看解析後，並列當年官方最終答案與現行作答對照。未提供獨立對照、待核原件、未生效與分階段施行均明示，不推定當年答案就是現行答案。「修法與函釋」集中列出待核選擇題及申論題，可搜尋並直接開啟。個人完成查證紀錄或標記已掌握不會消除教材的待核狀態。

題庫優先提供年度、科目、錯題／複習／收藏篩選；軌道、版本、主題、掌握狀態、難度及查證狀態收在進階篩選。收合後仍顯示已套用條件，重設可一次清除。原卷選題與來源資訊另以可展開區塊保留。

題庫另提供「練習目前篩選」，在目前年度、科目、主題及其他條件內挑選最多8題，仍排除教材及個人待核題；「全站每日8題」保留全站排序。篩選沒有可練題目時會提示並保留原條件，不自動切換到其他範圍。
