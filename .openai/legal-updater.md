# 警察特考題庫法規查核與更新

本網站為私人讀書站。Site 身分以同目錄 hosting.json 的 project_id 為準；保留現有存取對象。個人作答、收藏、熟悉度及草稿不在本更新範圍。

## 每次查核

1. 用 Sites get_site 取得目前網址、服務存取資訊及原始碼。查閱 lib/past-papers 的原題、初次註記；納入 110～115 年警察法規概要內、外軌及其申論，依各卷分別比對。讀取 `/api/legal-updates`，以最新紀錄為比較基準。不要把核對日期等同所有法令均已查完。
2. 查核考選部原卷／更正答案、全國法規資料庫沿革與施行條款、警政署主管法規及正式函釋、憲法法庭。先查已標 changed/review 及先前註記的未生效條文；優先檢視警察法、行政執行法、行政程序法、集會遊行法、公務人員行政中立法、警職法、刑訴、警械、道路交通、社維、單一窗口、失蹤人口、解送、攔檢追緝及越區程序。
3. 比較考試當時、現行已生效、公布未生效三種版本。新公布修正如尚未生效，標 announced；同次修正分段施行，標 mixed，逐項列施行日期。行政規則原件查不到仍保留 review，不猜文號或生效日。原題、原選項及當年官方給分答案不覆寫。
4. 確認有影響才新增 update 事件：補上 affected targetId、舊新差異、施行日、精確官方 HTTPS 來源、changed/review 狀態與 checkedAt；必要時同步更正逐項解析、修正文字、短背誦及申論擬答。現行作答結論置 currentAnswer，與當年給分分開。核對沒有新變動時只新增 check 紀錄，summary 寫實際查核範圍、待核及未生效事項。

## 持續資料寫入

網站目前可公開閱讀，因此 `app/api/legal-updates/route.ts` 不接受公開 POST。既有 D1 的 legal_content_events 保留為唯讀歷史；新的查核紀錄追加於原始碼 `lib/curated-updates.json`，經 Sites 版本發布。切勿為更新放寬或變更現有網站存取對象，也不要把服務憑證存入原始碼或排程文字。

先用 get_site 取得當前來源及存取狀態，GET `/api/legal-updates` 分頁讀取舊有紀錄作為比較基準。事件格式見 `lib/legal-updates.ts`：eventId 唯一，kind=check 不帶 patches，kind=update 附 1～40 筆 patches；所有事件附 checkedAt、summary、官方 sources，以及實際建立時間 `createdAt`（Unix 毫秒，須大於已保存最後事件的時間）。每筆 amendment.checkedAt 與事件同日，並附正式來源。對原始碼內題目、解析、申論及法條卡同步修正；原始題幹、選項原文及當年官方答案不得改寫。同步新增 patch，可覆蓋既有 D1 中較早的同題解析；歷史紀錄不可刪除或重編。不要把未生效新法覆蓋為現行原文。新條文與函釋原件不足時，使用 review 和 verified=false，勿猜測。

更新或查核記錄完成後執行既有試卷、法規更新及新增事件驗證，再依 Sites 原始碼工作流程提交並發布；保留現有 D1 學習紀錄與存取對象。從正式站 GET `/api/legal-updates` 逐頁讀回，確認 eventId、修正內容及較早事件均仍存在；未讀回不得宣稱成功。失敗先檢查、以相同 eventId 安全重試後再通知。無變化可追加 check 紀錄但不通知；若因發布或讀回失敗則通知。

通知只列有意義的變動、影響年度題號、生效日及尚需查核處。沒有變動可不另通知；查核／更新失敗則通知。此為定期查核，不承諾法令公布瞬間即更新。
